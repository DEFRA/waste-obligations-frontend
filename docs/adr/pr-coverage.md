## Material anchors considered but excluded

- General safe authentication return paths (`src/config/paths.js`, `src/server/plugins/require-auth.js`) predate the proxy work and lack bounded historical rationale in this assessment.
- `BaseApiService` response-cache mechanics remain disabled by default and no current factory enables them; there is insufficient evidence for a caching ADR.
- PRN feature flags and producer/CSO route registration are current rollout wiring, but history did not establish a retained cross-service policy independent of the feature.
- Translation exports, accessibility fixes, Sonar changes, snapshots, formatting and dependency updates were not promoted without an evidenced durable constraint.
